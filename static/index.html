What it does

A flowsheet that keeps up with a real, messy plan.

Not a static PDF flowchart — courses move terms, requirements shift, and a transfer credit or an honors thesis substitution shouldn't mean redrawing the whole chart by hand.

01
Term-by-term flowsheet

Collapsible term cards for the whole plan at a glance; expand any term for the full detail view.

02
Prereq & co-req tracking

Dependencies show up as tags right on the course, so a scheduling conflict is visible before it's a registration problem.

03
Technical elective counters

Live progress bars against major-specific elective requirements — credits and course count, tracked separately per major.

04
Fully editable, no database

Add, edit, delete, and drag courses between terms right in the dashboard. It writes straight to a JSON file — nothing to migrate or seed.

Make it yours

Three files, and it's your degree instead of mine.

1
Fork the repo
Clone it, run python app.py, and you have the full dashboard running locally on port 5050.
2
Add your own terms and courses
Click any course to edit it, hit "+ Add course" for a new one, drag between terms, or add/delete a term entirely — all from the dashboard itself.
3
Restyle with nocturne.css
Every color, radius, and shadow is a CSS variable in one design-system file — change the palette without touching layout markup.
